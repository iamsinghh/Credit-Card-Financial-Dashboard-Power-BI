# 📌 Overview

This project transforms raw credit card customer and transaction data into an interactive Power BI dashboard that provides real-time insights into key performance metrics and trends, enabling stakeholders to monitor and analyze credit card operations effectively.

The solution combines SQL, Power Query, DAX, and interactive visualizations to support data-driven decision-making.
